# Google Play Store Data Analysis and Visualization

## Introduction

This project focuses on the analysis of Google Play Store application data to identify meaningful patterns and relationships among application categories, ratings, reviews, installs, size, revenue, and other application attributes. The project uses Python-based data analysis and interactive visualizations to present the findings through individual HTML charts and a consolidated dashboard.

## Objectives

- To clean and preprocess Google Play Store data for analysis.
- To perform category-wise and feature-wise analysis of applications.
- To identify relationships between ratings, reviews, installs, size, and revenue.
- To apply specific filtering and analytical conditions to the dataset.
- To create interactive visualizations using Plotly.
- To present the analytical results through an interactive dashboard.

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Matplotlib
- Pytz
- Jupyter Notebook
- HTML/CSS

## Key Analytical Areas

### 1. Category Performance Analysis
Compares application categories based on installs, ratings, and reviews to identify high-performing categories.

### 2. Global Installation Analysis
Visualizes application installs across categories and geographical regions using an interactive choropleth map.

### 3. Free vs Paid Application Analysis
Compares free and paid applications based on average installs and revenue.

### 4. Installation Trend Analysis
Examines changes in total application installs over time and identifies significant month-over-month growth.

### 5. Application Size and Rating Analysis
Analyzes the relationship between application size, ratings, and installs using a bubble chart.

### 6. Cumulative Installation Analysis
Studies cumulative installs across application categories over time and highlights periods of significant growth.
